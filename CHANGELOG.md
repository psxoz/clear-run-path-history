# История изменений

## v1.2.0

- Вместо автоматической очистки при запуске открывается консольное меню. Каждое действие можно выбрать отдельно.
- Добавлен пункт, который отключает показ раздела «Недавно добавленные» в «Пуске».
- Добавлено открепление плиток справа в меню «Пуск» Windows 10, включая «Фотографии» и плитки-предложения.
- Сообщения об ошибках отображаются в консоли. После действия программа возвращается в меню.

## v1.1.0

Локальная версия. Изменения вошли в релиз `v1.2.0`.

- Добавлена очистка списка «Недавние файлы» в Проводнике. Программа убирает записи списка. Файлы на диске и закреплённые папки сохраняются.

## v1.0.0

- Первый релиз. При запуске утилита удаляла записи о локальных путях, которые появляются после ввода `/` в классическом окне `Win+R`.
