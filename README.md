# ClearRunPathHistory

Консольная утилита для выборочной очистки подсказок и списков Windows. При запуске она открывает меню. Чтобы выполнить действие, введите его номер и нажмите Enter.

## Скачать

Скачайте `ClearRunPathHistory.exe` из [последнего релиза](../../releases/latest). Архивы исходного кода (`.zip` и `.tar.gz`) доступны там же.

## Пункты меню

1. Очистить подсказки с локальными путями, которые появляются после ввода `/` в классическом окне `Win+R`.
2. Очистить список «Недавние файлы» в Проводнике.
3. Отключить показ «Недавно добавленных» в меню «Пуск». Его можно снова включить в разделе «Параметры» → «Персонализация» → «Пуск».
4. Открепить плитки справа в меню «Пуск» Windows 10, в том числе «Фотографии» и плитки-предложения.

Чтобы выйти, введите `0`.

При очистке записей файлы остаются на диске, а приложения остаются установленными.

На Windows 10 22H2 проверены консольное меню, запись настройки на тестовом ключе и доступность команды открепления для 12 плиток. Полное открепление и запуск на Windows 11 не проверялись.

## Собрать из исходников

Откройте PowerShell в папке с `ClearRunPathHistory.cs` и выполните команду.

```powershell
& "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /optimize+ /target:exe /platform:anycpu /reference:Microsoft.CSharp.dll /out:ClearRunPathHistory.exe ClearRunPathHistory.cs
```

История версий доступна в [CHANGELOG.md](CHANGELOG.md).
